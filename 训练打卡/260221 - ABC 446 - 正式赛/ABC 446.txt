        s_1 = x
        s_2 = y
        s_n = A*s_{n-1} + B*s_{n-2} (n>=3)
    给与三个整数，分别代表m、A、B，其中2<=m<=1000、0<=A,B<=m-1。输出一个整数，代表符合条件的整数对数量。

    [第一次思考]O(n*n)去遍历所有可用的整数对，然后用x和y是否为m的因子进行判断

    [Gemini 推理]正推所有整数对会超时，可以通过反推来找到所有不合法的整数对
    //  // 由 s_n​≡A*s_{n-1}+B*s_{n-2} (mod m) 可得到 B*s_{n-2}​≡s_n-A*s_{n-1} (mod m)

    //  // 形如 B*x​≡z-A*y (mod m)，z为每一个m的倍数，但每一个m的倍数有一个共同点，即均取余m为0
    //  // 反推时是假设每一个z为m的倍数(即z=0)，然后对于y可以从0到m遍历，从而解得每一个x，得到每一个非法整数对(x, y)
    //  // 对于每一个坏点(x, y)给与的s_n必然为0，那么后续的序列中必然存在多个元素为0(为m的倍数)，使得该序列必然非法
    //  // 那么就可以从每一个坏点(i, 0)或(0, i)开始，解得每一个非法整数对(x,y)，最后可得答案
