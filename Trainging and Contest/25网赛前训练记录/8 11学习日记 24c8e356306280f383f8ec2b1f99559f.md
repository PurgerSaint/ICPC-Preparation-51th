labuladong大佬的力扣例题：55.跳跃游戏

给你一个非负整数数组 `nums` ，你最初位于数组的 **第一个下标** 。数组中的每个元素代表你在该位置可以跳跃的最大长度。

判断你是否能够到达最后一个下标，如果可以，返回 `true` ；否则，返回 `false` 。

**示例 1：**

```
输入：nums = [2,3,1,1,4]
输出：true
解释：可以先跳 1 步，从下标 0 到达下标 1, 然后再从下标 1 跳 3 步到达最后一个下标。

```

**示例 2：**

```
输入：nums = [3,2,1,0,4]
输出：false
解释：无论怎样，总会到达下标为 3 的位置。但该下标的最大跳跃长度是 0 ， 所以永远不可能到达最后一个下标。
```

**提示：**

- `1 <= nums.length <= 104`
- `0 <= nums[i] <= 105`

---

每次从第一个下标开始，可前进的步数为 `[1,nums[0]]` 。题目要求是否能够到达最后一个下标，那么我们想的是是否存在一个路径，使得其可以从第一个位置走到最后一个位置。那么贪心来说，我们只需观察跳跃次数最少，即每次跳跃距离都最大的那条路径即可。

这样就得使用动态规划，从第一个位置开始，以`[1,nums[0]]`构建出每一条不同的路径。但这样耗时太久，不划算。那此时，我们可以直接每次跳最远，即对于nums[i]来说，我们只需关心跳后[i+1,i+nums[i]]的位置是否存在一个能跳到最远的步数。同时检查每次跳跃，是否存在死步（即无论怎样都会到跳跃长度为0的那一步，无法跳到最远）。如果跳后的步数在最后一个及其以后，即可解题。

```cpp
class Solution {
public:
    bool canJump(vector<int>& nums) {
        int maxFeat = 0;
        int n=nums.size();
        for(int i=0;i<n-1;i++){
            maxFeat = max(maxFeat,i+nums[i]);
            if(maxFeat<=i) return false;
        }
        return maxFeat >= n-1;
    }
};
```

labuladong大佬的力扣例题：45.跳跃游戏 II

给定一个长度为 `n` 的 **0 索引**整数数组 `nums`。初始位置为 `nums[0]`。

每个元素 `nums[i]` 表示从索引 `i` 向后跳转的最大长度。换句话说，如果你在索引 `i` 处，你可以跳转到任意 `(i + j)` 处：

- `0 <= j <= nums[i]` 且
- `i + j < n`

返回到达 `n - 1` 的最小跳跃次数。测试用例保证可以到达 `n - 1`。

**示例 1:**

```
输入: nums = [2,3,1,1,4]
输出: 2
解释: 跳到最后一个位置的最小跳跃数是2。
     从下标为 0 跳到下标为 1 的位置，跳1 步，然后跳3 步到达数组的最后一个位置。

```

**示例 2:**

```
输入: nums = [2,3,0,1,4]
输出: 2

```

**提示:**

- `1 <= nums.length <= 104`
- `0 <= nums[i] <= 1000`
- 题目保证可以到达 `n - 1`

---

本题相较于跳跃游戏I，增加了对步数的要求。回想I题的解题思路，我们每一次跳跃，都选择[i+1,i+nums[i]]中步数最大的那一个作为下一步跳跃的起点。

题目要求最小跳跃次数，则每次跳跃，我们要贪心地选择尽可能跳得最远的。

假定我们当前位于位置i，当前下一跳的位置，定是[i+1,i+nums[i]]中步数最大的那个下标。那么，我们要检查的范围就是[i+1,i+nums[i]]，当超出这个范围时，我们就要进行下一跳。

我们使用了一个变量maxFeat用于存储当前可通过跳跃抵达的最远位置， 每一次maxFeat的改变，就是下一跳的开始。同时，maxFeat的变化，也是我们整个跳跃路径的模拟演变。那么，我们不仅记录最大步数maxFeat，还需要记录一个边界end。end可以初始化为0，每当i到达边界时，就更新end为下一跳的最大位置，开始下一跳，同时步数加一。

```cpp
class Solution {
public:
    int jump(vector<int>& nums) {
        if(nums.size()<=1) return 0;
        int n=nums.size();
        /* 跳数,最远可达距离 */
        int jumps=0,maxFeat=0;
        /* 边界 */
        int end=0;
        for(int i=0;i<n-1;i++){
            /* 当前可跳转的区间为[1,nums[i]] */
            maxFeat = max(maxFeat,nums[i]+i);
            if(i==end){
                jumps++;
                /* 边界设置为当前跳数最大可达距离 */
                end=maxFeat;
                if(maxFeat>=n-1) return jumps;
            }
        }
        return -1;
    }
};
```

**Input**

The first input line contains a single integer *n* (1 ≤ *n* ≤ 1000) — the number of problems in the contest. Then *n* lines contain three integers each, each integer is either 0 or 1. If the first number in the line equals 1, then Petya is sure about the problem's solution, otherwise he isn't sure. Print a single integer — the number of problems the friends will implement on the contest.

Examples

input

3
1 1 0
1 1 1
1 0 0

output

2

input

2
1 0 0
0 1 1

output

1

**Note** 

In the first sample Petya and Vasya are sure that they know how to solve the first problem and all three of them know how to solve the second problem. That means that they will write solutions for these problems. Only Petya is sure about the solution for the third problem, but that isn't enough, so the friends won't take it.

力扣的简单题：121.买卖股票的最佳时机

给定一个数组 `prices` ，它的第 `i` 个元素 `prices[i]` 表示一支给定股票第 `i` 天的价格。

你只能选择 **某一天** 买入这只股票，并选择在 **未来的某一个不同的日子** 卖出该股票。设计一个算法来计算你所能获取的最大利润。

返回你可以从这笔交易中获取的最大利润。如果你不能获取任何利润，返回 `0` 。

**示例 1：**

```
输入：[7,1,5,3,6,4]
输出：5
解释：在第 2 天（股票价格 = 1）的时候买入，在第 5 天（股票价格 = 6）的时候卖出，最大利润 = 6-1 = 5 。
     注意利润不能是 7-1 = 6, 因为卖出价格需要大于买入价格；同时，你不能在买入前卖出股票。

```

**示例 2：**

```
输入：prices = [7,6,4,3,1]
输出：0
解释：在这种情况下, 没有交易完成, 所以最大利润为 0。

```

**提示：**

- `1 <= prices.length <= 105`
- `0 <= prices[i] <= 104`

---

我们可以遍历每一个价格，假定当前天数为i，如果我们要当天卖出，利润最高必须得在区间[0,i-1]中价格最低的那一天买入。此时可以通过二次循环之前的价格，寻找最小，但这样时间复杂度会很高。

此时可以同时记录价格最小值，该最小值定为该天之前最小价格的那一天。以及记录当前价格与之前最小值的差，即所得利润，保存最大值，即可找到答案。

```cpp
class Solution {
public:
    int maxProfit(vector<int>& prices) {
        /* 买入价格，利润 */
        int cost=INT_MAX,profit=0;
        for(int& price:prices){
            cost=min(cost,price);
            profit=max(profit,price-cost);
        }
        return profit;
    }
};
```

洛谷P1803：**凌乱的yyy / 线段覆盖**

给与n个比赛的开始和结束时间，要求尽可能多得参与比赛，返回比赛次数。

尽可能多得参加比赛，初步贪心思想是每场比赛时间尽可能地短，但无法保证每个短的比赛没有重叠，即可能选择一个短的比赛后，下个能选的是一个长的，造成浪费；亦或是暴力枚举选择每一个比赛，例如n个比赛，对每一场比赛i都有n-1个比赛选择，时间复杂度过于庞大。然后选择比赛最早的，但无法保证最早的那个亦是最合适的，极有可能再次陷入暴力枚举的状态下。

唯有选择按结束时间选择，选择结束时间早的。这样就可以将n个比赛参加最多的大问题，划分成n-1个比赛的小问题，使得前面的选择不影响后面的结果，促成最优子结构。

```cpp
#include<bits/stdc++.h>
using namespace std;
#define ll long long int
#define IOS ios::sync_with_stdio(false);cin.tie(0);
struct match{
	int start;
	int end;
};
bool c(match a,match b){
	return a.end < b.end;
}
int main(){
    IOS;
    int n;cin>>n;
    if(n<=1){
        cout<<n;
        return 0;
    }
    vector<match> a(n);
    for(int i=0;i<n;i++)
    	cin>>a[i].start>>a[i].end;
    sort(a.begin(),a.end(),c);
    int time=1,last=0;
    for(int i=1;i<n;i++){
    	if(a[last].end<=a[i].start){
    		time++;
    		last=i;
		}
	}
    cout<<time;
    return 0;
}
```

洛谷**P1208 [USACO1.3] 混合牛奶 Mixing Milk**

给与需要的牛奶总量n，m个农民能提供的奶量y和单价x，问怎么选最便宜？

本题按贪心的思想来说，总价最便宜，必定单价也是最便宜。假设需要n份牛奶，一个农民能提供单价8元、总量为n的牛奶，一个农民能提供单价3元、总量为x的牛奶，另一个则是单价5元、总量为y的牛奶。其中x+y=n。若按总量优先满足来看，选择的牛奶总价格是8n，比找另外两个奶农的总价3x+5y的价格要贵。则必定先选单价低的，然后逐步收购，这样使得总价最低。

```cpp
#include<bits/stdc++.h>
using namespace std;
#define ll long long int
#define IOS ios::sync_with_stdio(false);cin.tie(0);
int main(){
    IOS;
    int n,m;cin>>n>>m;
    vector<pair<int,int>> a(m);
    for(int i=0;i<m;i++)
    	cin>>a[i].first>>a[i].second;
    sort(a.begin(),a.end(),[](pair<int,int>& x,pair<int,int>& y){
    	return x.first<y.first;
	});
	int sum=0;
	for(pair<int,int>& i:a){
		if(n<=0) break;
		int& x=i.first,y=i.second;
		sum+=x*min(n,y);
		n-=y;
	}
	cout<<sum;
    return 0;
}
```
