力扣704.二分查找

给与一个整数target和一个数组nums，问nums中是否存在target，有就返回下标，否则返回-1。

使用二分搜索准确查找数组中第一个等于target的下标即可。

```cpp
class Solution {
public:
    int search(vector<int>& nums, int target) {
        int left=0,right=nums.size()-1;
        while(left<=right){
            int mid=left+((right-left)>>1);
            if(nums[mid]<target) left=mid+1;
            else if(nums[mid]>target) right=mid-1;
            else return mid;
        }
        return -1;
    }
};
```

力扣35.搜索插入位置

给与数组nums，找到数组中第一个大于或等于target的下标。

开区间写法（left为可能的解，right不在解的范围之内）

```cpp
class Solution {
public:
    int searchInsert(vector<int>& nums, int target) {
        int n=nums.size();
        int left=0,right=n;
        while(left<right){
            int mid=left+((right-left)>>1);
            if(target>nums[mid]) left=mid+1;
            else right=mid;
        }
        return left;
    }
};
```

闭区间写法（[left,right]范围就是解的范围）

```cpp
class Solution {
```

力扣 69.x的平方根

给与一个整数x，在不使用库函数的情况下找出其算术平方根。

使用二分查找，令左值为1，右值为x，当中值的平方小于x时，更新右值；当中值的平方大于x时，更新左值；当中值的平方等于x时，找到答案。同时，令循环出口条件为左值小于或等于右值，避免算术平方根为小数的情况。

```cpp
class Solution {
public:
    int mySqrt(int x) {
        if(x<2) return x;
        /* 当x>=4时,其平方根sqrt(x)<(x/2) */
        long long left=1,right=x>>1;
        long long res=-1;
        while(left<=right){
            //long long mid=(left+right)/2;
            /* 优化版,避免溢出 */
            long long mid=left+((right-left)>>1);
            if(mid*mid<x) left=mid+1;
            else if(mid*mid>x) right=mid-1;
            else{
                res=mid;
                break;
            }
        }
        return res!=-1?res:right;
    }
};
```

力扣410.分割数组的最大值

给与一个数组nums，要求将其分成k个子数组，子数组的最大值要最小。

最大值最小化问题。由于我们不知道最大值具体取值要多少，必须要使用二分来推测模拟。通过子数组和的最大值范围为[maxi,sum]，可知二分的范围。使用二分来猜测一个值mid，然后通过子数组和超过mid，来计算子数组个数。通过子数组个数等于k，即可找到子数组的最大值。

**子数组和的最大值越大，子数组数量就越少；子数组和的最大值越小，子数组数量就越多。**所以通过猜测值选出的子数组个数比k少甚至相等时，代表猜的大了，需要向左缩小范围继续猜。

```cpp
class Solution {
public:
    int splitArray(vector<int>& nums, int k) {
        /* 子数组最大值必定在[maxi,sum]之中 */
        long long int maxi=*max_element(nums.begin(),nums.end()),sum=reduce(nums.begin(),nums.end());
        long long left=maxi,right=sum;
        /* <用于搜索最小可行值,<=用于寻找精准值 */
        while(left<right){
            /* 使用二分,通过mid来逼近寻找自数字 */
            long long mid = left + ((right-left)>>1);
            /* 子数组大小,分出的子数组个数 */
            long long temp=0,cnt=1;
            for(int& i:nums){
                temp+=i;    //计算当前子数组的和
                /* 如果子数组的和超过假定的值,就开辟一个新的子数组 */
                if(temp>mid){
                    temp=i;
                    cnt++;
                }
            }
            /* 个数比预期要多,代表猜测值太小了 */
            if(cnt<=k) right=mid;
            else left=mid+1;
        }
        return left;
    }
};
```

力扣2517.礼盒的最大甜蜜度

给一个数组price，每一个price[i]代表i类糖果的价格，请问如何由k类糖果组成的礼盒，使其甜蜜度（礼盒中任意两种糖果价格绝对差的最小值）最大。

二分中最小值最大化问题。可知题目要猜测的绝对差最大，绝对差的范围为[0,max{price[i]}-min{price[i]}]。然后可以根据这个范围使用二分来逼近、猜测和寻找该绝对差。

**数组绝对差的最小值越小，可选元素就多；数组绝对差的最小值越大，可选元素越少。**所以通过猜测值选出的糖果数量比p多甚至与p相等时，代表甜蜜度猜的小了，需要向右缩小范围继续猜。

```cpp
class Solution {
public:
    int maximumTastiness(vector<int>& price, int k) {
        int n=price.size();
        sort(price.begin(),price.end());
        int left=0,right=price[n-1]-price[0]+1;
        /* 循环+1避免死循环（当left=right时） */
        while(left<right){
            /* 猜测的甜蜜度mid */
            int mid=left+((right-left+1)>>1);
            /* 当前礼盒假设已选1个糖果,第一个 */
            int prep=price[0],cnt=1;
            for(int& i:price){
                //每个绝对差超过猜测值的糖果都会被放入礼盒中
                //这样才会使得猜测值为最小
                if(i-prep>=mid){
                    cnt++;
                    prep=i;
                }
            }
            if(cnt>=k) left=mid;
            else right=mid-1;
        }
        return left;
    }
};
```

2616.最小化数对的最大差值

给与一个数组nums和整数p，找到nums中p对任意数对，且他们之中数对差值的最大值最小。

二分的最大值最小化问题。

**数对差值的最大值越大，可选数对个数就越多；数对差值的最小值越小，可选数对个数就越少。**所以当通过猜测值匹配出来的数对个数与p相等甚至比p多时，代表猜的值太大了，需要向左缩小范围来重新猜。

```cpp
class Solution {
public:
    int minimizeMax(vector<int>& nums, int p) {
        int n=nums.size();
        sort(nums.begin(),nums.end());
        int left=0,right=nums[n-1]-nums[0];
        while(left<right){
            int mid=left+((right-left)>>1);
            int cnt=0; //数对个数
            for(int i=1;i<n;i++)
            //每个差值都比mid小,这样即可使得mid最大
                if(nums[i]-nums[i-1]<=mid){
                    cnt++;
                    i++;
                }
            //个数比要求的多,就缩小范围继续猜测
            if(cnt>=p) right=mid;
            else left=mid+1;
        }
        return left;
    }
};
```

洛谷P1824.**[USACO05FEB] 进击的奶牛 Aggressive Cows G**

二分的最小值最大化问题。**两间牛舍的最小距离越小，牛可以放得更多，需要的牛舍越多；最小距离越大，牛放得就少了，需要的牛舍越少。**所以当预选出来的牛舍比预计要多或相等时，代表猜的值太小了，需要往右缩小。

```cpp
#include<bits/stdc++.h>
using namespace std;
#define ll long long int
#define IOS ios::sync_with_stdio(false);cin.tie(0);
/* 洛谷P1824 */
/* 最小值最大化 */
int main(){
    IOS;
    //两间牛舍的最小距离越小，牛可以放得更多，需要的牛舍越多；最小距离越大，牛放得就少了，需要的牛舍越少。
    int n,m;cin>>n>>m;
    vector<int> a(n);
    for(int i=0;i<n;i++) cin>>a[i];
    sort(a.begin(),a.end());
    int left=0,right=a[n-1]-a[0];
    while(left<right){
        int mid=left+((right-left+1)>>1);
        int cnt=1,f=a[0];
        for(int i=1;i<n;i++){
            //找比mid大的,使得mid为最小
            if(a[i]-f>=mid){
                cnt++;
                f=a[i];
            }
        }
        //牛舍比预计要多,代表猜的值太小,需要往右扩大
        if(cnt>=m) left=mid;
        else right=mid-1;
    }
    cout<<left;
    return 0;
}
```
