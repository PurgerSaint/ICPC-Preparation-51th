力扣**204. 计数质数**

给定整数 `n` ，返回 *所有小于非负整数 `n` 的质数的数量* 。

埃氏筛寻找质数（素数）的标准模版。

<aside>
💡

大数时使用哈希表会因为频繁扩容和寻找，导致超时；数组只需移动指针访问即可。

</aside>

```cpp
class Solution {
public:
  int countPrimes(int n) {
    vector<bool> prime(n + 1, true);
    /* n内的因子最多不超过sqrt(n) */
    for (int i = 2; i * i < n; i++) {
      if (prime[i]) {
        // 内层循环也修改，避免重复运算
        for (int j = i * i; j < n; j += i)
          prime[j] = false;
      }
    }
    int count = 0;
    for (int i = 2; i < n; i++)
      if (prime[i])
        count++;
    return count;
  }
};
```

codeforces 102267B B. Primes

给与一个整数n，返回可以相加为n的两个质数，否则返回-1。

先用埃氏筛寻找质数，然后判断即可。

```cpp
#include <bits/stdc++.h>
using namespace std;
#define IOS                                                                    \
  ios::sync_with_stdio(false);                                                 \
  cin.tie(0);
#define ll long long int
int main() {
  IOS;
  ll n;
  cin >> n;
  vector<bool> prime(n + 1, true);
  for (int i = 2; i * i < n; i++)
    if (prime[i])
      for (int j = i * i; j < n; j += i)
        prime[j] = false;
  for (int i = 2; i * i < n; i++) {
    int &x = i, y = n - i;
    if (prime[x] && prime[y]) {
      cout << x << " " << y;
      return 0;
    }
  }
  cout << -1;
  return 0;
}
```

力扣1979.找出数组的最大公约数

给你一个整数数组 `nums` ，返回数组中最大数和最小数的 **最大公约数** 。

两个数的 **最大公约数** 是能够被两个数整除的最大正整数。

使用欧几里得法或辗转相除法求最大公约数（GCD）即可。

注：辗转相除法效率低于欧几里得法。

```cpp
class Solution {
public:
  /* 欧几里得法 */
  int gcd(int a, int b) { return b == 0 ? a : gcd(b, a % b); }
  /* 辗转相除法 */
  int gcd1(int a, int b) {
    return a == b ? a : (a > b ? gcd1(a - b, b) : gcd1(a, b - a));
  }
  int findGCD(vector<int> &nums) {
    return gcd(*min_element(nums.begin(), nums.end()),
               *max_element(nums.begin(), nums.end()));
  }
};
```

力扣1.两数之和

找到nums中两个相加值为target的不同元素下标。

原本是双循环，但是可以用哈希表进行优化，使得一层循环寻找第一个数字，然后找target与第一个数之差是否存在数组中即可。纯哈希表算法。

```cpp
class Solution {
public:
    vector<int> twoSum(vector<int>& nums, int target) {
        unordered_map<int,int> hash;
        for(int i=0;i<nums.size();i++){
            int t=target-nums[i];
            if(hash.find(t)!=hash.end())    return {hash[t],i};
            hash[nums[i]]=i;
        }
        return {};
    }
};
```

力扣1011.在D天送达包裹的能力

传送带上的包裹必须在 `days` 天内从一个港口运送到另一个港口。

传送带上的第 `i` 个包裹的重量为 `weights[i]`。每一天，我们都会按给出重量（`weights`）的顺序往传送带上装载包裹。我们装载的重量不会超过船的最大运载重量。

返回能在 `days` 天内将传送带上的所有包裹送达的船的最低运载能力。

二分题目。船的最大装载容量在包裹最大重量和所有包裹总重之间，最快1天，最慢天数为包裹数量。可以使用二分寻找船的最大装载容量，然后计算该容量需要的天数，根据天数和实际需要的天数进行比较，更新二分范围。天数越低，代表船能装的货越多，反之越少。

```cpp
class Solution {
public:
    int shipWithinDays(vector<int>& weights, int days) {
        int n=weights.size();
        // 题目找的是最大运载重量
        // 并且是最小天数下的最大重量
        // 即最大化最小值
        // 模拟重量，计算天数，更新区间即可
        // 区间为[最重货物,所有货物之和]
        int left = *max_element(weights.begin(),weights.end()),
            right = accumulate(weights.begin(),weights.end(),0);
        while(left <= right) {
            int mid = left + ((right - left)>>1);

            // 需要的天数,每天的运输量
            int cnt = 1,sum = weights[0];
            for (int i = 1; i < n; i++) {
                sum += weights[i];
                // 如果每天的运货量超过预估量
                // 就加1天
                if (sum > mid) {
                    cnt ++;
                    sum = weights[i];
                }
            }

            // 运货的天数越多,代表每天运输的货物量越少
            // 运货的天数越少,代表每天运输的货物量越大
            // 题目要求的是天数最小,即范围尽可能往左靠
            // 更新右值的条件是实际的运货量高于估计的
            // 根据分析,当天数少于需要时,我们就需要更新右值
            if(cnt <= days) right = mid - 1;
            else left = mid + 1; 
        }
        return left;
    }
};
```

AcWing **102. 最佳牛围栏**

农夫约翰的农场由 N 块田地组成，每块地里都有一定数量的牛，其数量不会少于 1 头，也不会超过 2000 头。 约翰希望用围栏将一部分连续的田地围起来，并使得围起来的区域内每块地包含的牛的数量的平均值达到最大。 围起区域内至少需要包含 F 块地，其中 F 会在输入中给出。 在给定条件下，计算围起区域内每块地包含的牛的数量的平均值可能的最大值是多少。 

输入格式

第一行输入整数 N 和 F，数据间用空格隔开。

接下来 N 行，每行输入一个整数，第 i+1 行输入的整数代表第 i 片区域内包含的牛的数目。

输出格式

输出一个整数，表示平均值的最大值乘以 1000 再 向下取整 之后得到的结果。

经典的二分题，寻找一个可能的最大值。能找到二分的区间，为平均值的最大值（0到数组中最大），然后就按二分的做法，模拟找到一个可能的最大值。

```cpp
#include <bits/stdc++.h>
using namespace std;
#define IOS                                                                    \
  ios::sync_with_stdio(false);                                                 \
  cin.tie(0);
#define ll long long int
int main() {
    IOS;
    // N块地,要求围起区域内含F块地 
    int n,f;cin>>n>>f;
	vector<int> a(n+1,0);
	for (int i=1;i<=n;i++)	cin>>a[i];
	
	// 题目要求围起区域内牛数量平均值最大
	// 但不止多少,如果使用暴力,复杂度很高
	// 此时可以使用二分来寻找可能的平均值
	// 平均值范围为0到数组中最大值
	double l = 0, r = *max_element(a.begin(),a.end());
	while (r - l > 1e-5) {
		double mid = l + ((r - l)/2);
		
		// c++的lambda函数写法
		// [&]代表接收之前定义的所有函数和变量
		// auto代表自动判断返回值
		// 该函数控制什么时候更新范围 
		auto check = [&](double mid) {
			vector<double> sum(n+1,0);
			for(int i=1;i<=n;i++)	sum[i] = sum[i-1] + a[i] - mid;
			
			// 从第一个元素开始,到第1+f个元素的固定子数组
			// 即长度为f的滑动窗口
			// 只需检测该子数组内的平均值是否能够大于估计值
			// 即代表在当前估计值下,可以拥有更大的估计值[估小了]
			double v = INT_MAX;	//窗口前的总和
			for(int i = 0,j = f;j<=n;i++,j++){
				/*
					sum[j] - sum[i] >= 0：是长度恰好为f的区间
					但题目说的是至少为f,即可以超过f
					所以这里是寻得该滑动窗口之前最小前缀和 
				*/
				v = min(v, sum[i]);
				if(sum[j] - v >= 0) return true;
			} 
			return false;
		};
		
		// 题目要求最大,即范围尽可能往右靠
		// 所以check函数可以控制为什么时候要扩大范围 
		if (check(mid))  l = mid;
		else r = mid;
	}
	// 由于r会略大于l,使得r才是正确答案 
	cout<<(int)(r*1000);
    return 0;
}
```
