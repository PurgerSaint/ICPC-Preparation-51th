### 力扣509.斐波那契数

**斐波那契数** （通常用 `F(n)` 表示）形成的序列称为 **斐波那契数列** 。该数列由 `0` 和 `1` 开始，后面的每一项数字都是前面两项数字的和。也就是：

$F(0) = 0，F(1) = 1，F(n) = F(n - 1) + F(n - 2)，其中 n > 1$

给定 `n` ，请计算 `F(n)` 。

> 定义dp[i]为i的斐波那契数，即F(i)
初始化dp[0]=0,dp[1]=1
然后往后状态转移dp[i] = dp[i-1] + dp[i-2]
> 

```cpp
class Solution {
public:
    int fib(int n) {
        vector<int> dp(n + 1);
        dp[0] = 0;
        dp[1] = 1;
        for (int i = 2; i <= n; i++)
            dp[i] = dp[i-1] + dp[i-2];
        return dp[n];
    }
};
```

### 力扣**322. 零钱兑换**

给你一个整数数组 `coins` ，表示不同面额的硬币；以及一个整数 `amount` ，表示总金额。

计算并返回可以凑成总金额所需的 **最少的硬币个数** 。如果没有任何一种硬币组合能组成总金额，返回 `-1` 。

你可以认为每种硬币的数量是无限的。

> 此题不是DPtable，是递归DP
定义dp[i]为零钱i需要找零的硬币数
遍历所有硬币金额，若i减去硬币金额不为0，dp[i]就是该状态加一
否则如果为0，就返回0
初始化不能为-1，因为题目定义非正常状态为-1
> 

```cpp
class Solution {
private:
    vector<int> lt;
public:
    int coinChange(vector<int>& coins, int amount) {
        lt = vector<int>(amount + 1, -2);
        return dp(amount, coins);
    }
private:
    int dp(int amount, vector<int>& coins) {
        if (amount == 0) return 0;
        if (amount < 0) return -1;
        if (lt[amount] != -2) return lt[amount];
        int ans = INT_MAX;
        for (int& coin : coins) {
            int res = dp(amount - coin, coins);
            if (res == -1) continue;
            ans = min(res + 1, ans);
        }
        lt[amount] = ans == INT_MAX ? -1 : ans;
        return lt[amount];
    }
};
```

### 力扣300.最长递增子序列

给你一个整数数组 `nums` ，找到其中最长严格递增子序列的长度。

**子序列** 是由数组派生而来的序列，删除（或不删除）数组中的元素而不改变其余元素的顺序。例如，`[3,6,2,7]` 是数组 `[0,3,1,6,2,2,7]` 的子序列。

> 定义dp[i]为当前nums{0...i}的最长递增序列长度
题目要求是最长
那么转移状态就是i之前最长的长度加一即可
> 

```cpp
class Solution {
public:
    int lengthOfLIS(vector<int>& nums) {
        int n = nums.size();
        vector<int> dp(n, 1);
        for (int i = 1; i < n; i++)
            for (int j = 0; j < i; j++)
                if (nums[i] > nums[j])
                    dp[i] = max(dp[i], dp[j] + 1);
        return *max_element(dp.begin(), dp.end());
    }
};
```

### 力扣**931. 下降路径最小和**

给你一个 `n x n` 的 **方形** 整数数组 `matrix` ，请你找出并返回通过 `matrix` 的**下降路径** **的 **最小和** 。

**下降路径** 可以从第一行中的任何元素开始，并从每一行中选择一个元素。在下一行选择的元素和当前行所选元素最多相隔一列（即位于正下方或者沿对角线向左或者向右的第一个元素）。具体来说，位置 `(row, col)` 的下一个元素应当是 `(row + 1, col - 1)`、`(row + 1, col)` 或者 `(row + 1, col + 1)` 。

> 定义dp[i][j]为[i,j]的最小下降和
由左上、上方和右上三个最小和决定当前下降路径
> 

```cpp
class Solution {
public:
    int minFallingPathSum(vector<vector<int>>& mat) {
        int n = mat.size(), m = mat[0].size();
        vector<vector<int>> dp(n, vector<int>(m, INT_MAX));
        for (int j = 0; j < m; j++) dp[0][j] = mat[0][j];
        for (int i = 1; i < n; i++)
            for (int j = 0; j < m; j++) {
                dp[i][j] = mat[i][j];
                if (j == 0) dp[i][j] += min(dp[i-1][j+1], dp[i-1][j]);
                else if (j == m - 1) dp[i][j] += min(dp[i-1][j-1], dp[i-1][j]);
                else dp[i][j] += min(dp[i-1][j-1], min(dp[i-1][j], dp[i-1][j+1]));
            }
        return *min_element(dp[n-1].begin(), dp[n-1].end());
    }
};
```

### 力扣72.编辑距离

给你两个单词 `word1` 和 `word2`， *请返回将 `word1` 转换成 `word2` 所使用的最少操作数*  。

你可以对一个单词进行如下三种操作：

- 插入一个字符
- 删除一个字符
- 替换一个字符

> 定义dp[i][j]为使得word2{0,...,j}与word1{0,...,i}相等所需要的次数
dp[i][0]初始化为1到n（word1转换成空字符串的次数）
dp[0][j]初始化为1到m（空字符串转换成word2的次数）
如果s[i] == s[j] ，则该状态等于dp[i-1][j-1]
否则插入一个字符，即dp[i-1][j] + 1
亦或是删除一个字符，即dp[i-1][j] + 1
更或是替换一个字符，即dp[i-1][j-1] + 1
取得这俩的最小值即可
> 

```cpp
class Solution {
private:
    int min3(int a, int b, int c) {
        return min(a, min(b, c));
    }
public:
    int minDistance(string s, string t) {
        int n = s.size(), m = t.size();
        vector<vector<int>> dp(n + 1, vector<int>(m + 1, 0));
        for (int i = 1; i <= n; i++) dp[i][0] = i;
        for (int j = 1; j <= m; j++) dp[0][j] = j;
        for (int i = 1; i <= n; i++)
            for (int j = 1; j <= m; j++)
                if (s[i - 1] == t[j - 1])
                    dp[i][j] = dp[i-1][j-1];
                else
                    dp[i][j] = min3(dp[i-1][j], dp[i-1][j-1], dp[i][j-1]) + 1;
        return dp[n][m];
    }
};
```

### 力扣53.最大子数组和

给你一个整数数组 `nums` ，请你找出一个具有最大和的连续子数组（子数组最少包含一个元素），返回其最大和。

**子数组**是数组中的一个连续部分。

> 定义dp[i]是数组中从0到i的最大连续子数组和
dp[i-1]转移到dp[i]当且仅当dp[i-1]+nums[i]大于dp[i-1]
> 

```cpp
class Solution {
public:
    int maxSubArray(vector<int>& nums) {
        int n = nums.size();
        vector<int> dp(n, 0);
        dp[0] = nums[0];
        for (int i = 1; i < n; i++)
            dp[i] = max(nums[i] + dp[i - 1], nums[i]);
        return *max_element(dp.begin(), dp.end());
    }
};
```

### **力扣1143. 最长公共子序列**

给定两个字符串 `text1` 和 `text2`，返回这两个字符串的最长 **公共子序列** 的长度。如果不存在 **公共子序列** ，返回 `0` 。

一个字符串的 **子序列** **是指这样一个新的字符串：它是由原字符串在不改变字符的相对顺序的情况下删除某些字符（也可以不删除任何字符）后组成的新字符串。

- 例如，`"ace"` 是 `"abcde"` 的子序列，但 `"aec"` 不是 `"abcde"` 的子序列。

两个字符串的 **公共子序列** 是这两个字符串所共同拥有的子序列。

> 定义dp[i][j]为s{0...i}和t{0...j}相同子序列的最大长度
初始化全部为0即可
如果当前字符相同，就是dp[i-1][j-1]+1
否则就是dp[i-1][j]（设t[j-1]为子序列一部分）和d[i][j-1]（设s[i-1]为子序列一部分）取最大值即可
> 

```cpp
class Solution {
public:
    int longestCommonSubsequence(string s, string t) {
        int n = s.size(), m = t.size();
        vector<vector<int>> dp(n + 1, vector<int>(m + 1, 0));
        for (int i = 1; i <= n; i++)
            for (int j = 1; j <= m; j++)
                if (s[i - 1] == t[j - 1])
                    dp[i][j] = dp[i-1][j-1] + 1;
                else
                    dp[i][j] = max(dp[i-1][j], dp[i][j-1]);
        return dp[n][m];
    }
};
```

### 力扣**712. 两个字符串的最小ASCII删除和**

给定两个字符串`s1` 和 `s2`，返回 *使两个字符串相等所需删除字符的 **ASCII** 值的最小和* 。

> 定义dp[i][j]为s{0...i}和t{0...j}的最小ASCII删除和
dp[0][j]需要设定为字符串t的ASCII和
dp[i][0]需要设定为字符串s的ASCII和
如果字符相同，就不用删除直接继承dp[i-1][j-1]
否则删除s[i-1]，就是dp[i-1][j] + s[i-1]
亦或是删除t[j-1]，就是dp[i][j-1] + t[j-1]
这俩删除取最小即可
> 

```cpp
class Solution {
public:
    int minimumDeleteSum(string s, string t) {
        int n = s.size(), m = t.size();
        vector<vector<int>> dp(n + 1, vector<int>(m + 1, 0));
        for (int i = 1; i <= n; i++) dp[i][0] = dp[i-1][0] + s[i-1];
        for (int j = 1; j <= m; j++) dp[0][j] = dp[0][j-1] + t[j-1];
        for (int i = 1; i <= n; i++)
            for (int j = 1; j <= m; j++)
                if (s[i - 1] == t[j - 1])
                    dp[i][j] = dp[i-1][j-1];
                else
                    dp[i][j] = min(dp[i-1][j] + s[i - 1], dp[i][j-1] + t[j - 1]);
        return dp[n][m];
    }
};
```
