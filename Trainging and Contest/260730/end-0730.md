## 题目详情
A normal binary decomposition can be represented as $n=\overline{a_{31}a_{30}\cdots a_0}$, where $a_i \in \{0,1\}$.
Now, there is a strange binary decomposition, still represented as $n=\overline{a_{31}a_{30}\cdots a_0}$, but it needs to satisfy:
1.  For $i=0,1,\cdots,31$, $a_i \in \{-1,0,1\}$.
2.  For $i=0,1,\cdots,30$, $a_i$ and $a_{i+1}$ cannot both be 0, i.e., $a_i^2 + a_{i+1}^2 \neq 0$.
3.  $$
    \sum_{i=0}^{31} a_i 2^i = n
    $$
Given a non-negative integer $n$, find the above binary decomposition of $n$, or determine that it cannot be decomposed.
> $1<=T<=10^4, 0<=n<=2^30$
## 思考
> 我发现前缀和中第2位到第30位，恰好与数组(2的次方)第3位到第31位恰好乘一  
如果 $n$ 是奇数，可以先将最后一位设置1，其余设置为-1，此时可得到1  
如果 $n$ 是偶数，可以先将最后一位设置1，其余设置为-1，第一位设置为0，此时可得到2  
此时，如果 $n/2$ 是两个偶数组成的，且这个数恰好在次方数组内，就对应数设置为1即可  
如果 $n/2$ 是两个奇数组成的，且这个数恰好在前缀和数组内，就这个数及其之前设置为1即可  
但这里有个特殊情况，$n/2$ 可能由多个偶数和奇数组成的，且这些数都在前缀和或次方数组内，不好寻找  
故不可行，构造失败
## 提交详情

```md
首先，我们可以证明 4 的倍数一定不可以分解，因为此时必然有 a_{0} = a_{1} = 0。
否则，可以先将序列 a 全赋值为 1，然后再根据 2^32 − 1 − x 的在二进制下 2^i 那一位决定 a_{i−1} 是否变为 −1。
此时需要修正的部分是 x 为偶数的情况，此时将 a_{0} 变为 0 就可以了。
时间复杂度 O(T log n)。
```

```cpp
bool dfs(int idx, long long V, vector<int>& ans, vector<set<long long>>& visited) {
    if (idx == 32) {
        return V == 0;
    }
    if (visited[idx].count(V)) {
        return false;
    }
    if (V % 2 == 0) {
        if (idx > 0 && ans[idx - 1] == 0) {
            visited[idx].insert(V);
            return false;
        }
        ans[idx] = 0;
        if (dfs(idx + 1, V / 2, ans, visited)) return true;
    } else {
        ans[idx] = 1;
        if (dfs(idx + 1, (V - 1) / 2, ans, visited)) return true;
        
        ans[idx] = -1;
        if (dfs(idx + 1, (V + 1) / 2, ans, visited)) return true;
    }
    
    visited[idx].insert(V);
    return false;
}

void solve() {
    long long n;
    cin >> n;  
    vector<int> ans(32);
    vector<set<long long>> visited(32);
    if (dfs(0, n, ans, visited)) {
        cout << "YES\n";
        for (int i = 0; i < 32; ++i) {
            cout << ans[i] << (i % 8 == 7 ? "" : " ");
            if (i % 8 == 7) cout << "\n"; 
        }
    } else {
        cout << "NO\n";
    }
}
```
