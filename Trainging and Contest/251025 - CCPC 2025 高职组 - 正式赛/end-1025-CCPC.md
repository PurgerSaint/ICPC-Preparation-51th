# 1. 题目详情
## A.环状线
小 C 生活的比特市公共交通系统发达，地铁线路众多。
今天小 C 决定搭乘地铁 7 号线去找小 Q 玩，而地铁 7 号线是一个环状线路——不管往哪个方向搭乘都能到达 7 号线上的任意站点！  
具体的，7 号线上共有 $n$ 个站（$n$ 为奇数），编号为 $1, 2, \cdots, n$。环状线由两个相反的环形线路构成：第一条运营的方向是 $1 \to 2 \to 3 \to \cdots \to n \to 1 \to \cdots$，第二条运营的方向是 $1 \to n \to n-1 \to \cdots \to 2 \to 1 \to n \to \cdots$。假设任意相邻两站距离相同，地铁两条线路从任意一站前往下一站所需的时间也相同。  
现在小 C 在编号为 $s$ 的站，小 Q 家在编号为 $t$ 的站。小 C 虽然不管坐哪个方向都能到达小 Q 的家，但他还是想要尽快到达。你可以帮小 C 确定他应该乘坐哪一个线路吗？  
*输入格式*  
输入一行包含三个整数 $n, s, t$（$3 \leq n \leq 100$，$1 \leq s, t \leq n$，$s \neq t$，$n$ 为奇数），分别代表环状线上的站点数量，小 C 所在的站点编号，小 Q 家所在的站点编号。  
*输出格式*  
输出一个整数 $x$（$x \in \{1, 2\}$），代表最优策略下，小 C 会搭乘第 $x$ 条线路。

## B.爬山  
小 C 喜欢爬山，但他的体能一般，不能连续爬升太高。  
这天小 C 决定去爬比特峰。比特峰共有 $n$ 个景点，第 $i$ 个景点的海拔为 $h_i$ 米。  
景点之间共有 $m$ 条双向线路，第 $i$ 条线路连通景点 $u_i$ 和景点 $v_i$，小 C 从任意方向走过第 $i$ 条线路所需的时长均为 $t_i$ 分钟。  
小 C 在爬山过程中会累积疲劳值，初始的疲劳值为 0，并且小 C 能够忍受的最大疲劳值为 $H$。  
假设当前小 C 位于某个景点 $x$，且存在一条从景点 $x$ 到景点 $y$ 的线路：  
- 如果景点 $x$ 比景点 $y$ 的海拔高，那么这是一段轻松的下坡路，小 C 如果选择走这条线路，体力得到了恢复，疲劳值被清零。  
- 否则，如果小 C 选择走这条线路，疲劳值会累积 $h_y - h_x$。小 C 只能在保证积累的疲劳值不超过 $H$ 的前提下走这条线路。  
现在小 C 从 1 号景点出发，只能通过这些线路在景点间移动。对于每个景点，小 C 想知道他最快需要多少分钟可以到达该景点，或永远无法到达？  
*输入格式*  
第一行包含三个正整数 $n, m, H$（$2 \leq n \leq 10^4$，$0 \leq m \leq 2 \times 10^4$，$1 \leq H \leq 100$），分别表示景点的个数、线路的条数，以及小 C 能忍受的最大疲劳值。  
第二行包含 $n$ 个正整数 $h_1, h_2, \cdots, h_n$（$1 \leq h_i \leq 10^9$），代表每个景点的海拔。  
接下来 $m$ 行，每行三个正整数 $u_i, v_i, t_i$（$1 \leq u_i, v_i \leq n$，$u_i \neq v_i$，$1 \leq t_i \leq 10^9$），代表一条线路连接的两个景点和所需的时长。  
*输出格式*  
输出一行 $n-1$ 个整数，第 $i$ 个整数代表小 C 到达第 $i+1$ 号景点所需的最短时间（以分钟为单位）。如果小 C 永远无法到达该景点，输出 $-1$。  

## C.短视频   
小 Q 最近沉迷刷短视频不能自拔，经常不知不觉几个小时就过去了。  
为了研究小 Q 沉迷的原因，小 C 建立了如下模型：  
小 Q 现在准备刷短视频，预计刷 $T$ 秒。小 Q 手机中缓存了 $n$ 个短视频，第 $i$ 个短视频时长为 $t_i$ 秒，对小 Q 的吸引力为 $k_i$。  
小 Q 会按照下标顺序依次浏览全部 $n$ 个短视频，切换短视频不需要时间。在每一秒结束时，小 Q 都会思考是否要停止刷短视频：  
- 如果此时全部 $n$ 个短视频都播放完了，那么小 Q 会停止刷短视频。  
- 否则，如果当前累积的观看时长不超过 $T$ 秒，那么小 Q 会继续正常播放短视频。  
- 否则，假设当前一共观看了 $x$ 秒（$x > T$）：如果当前短视频的吸引力小于 $x - T$，则小 Q 会停止观看这一个短视频。如果这是最后一个短视频，那么小 Q 会停止刷短视频，否则小 Q 会开始看下一个短视频。注意此时不论下一个短视频对小 Q 的吸引力如何，小 Q 只会在下一秒结束前再做判断。  
给定缓存的视频信息，你可以帮小 C 计算出小 Q 总共会看多少秒的短视频吗？  
*输入格式*  
第一行包含两个正整数 $n, T$（$1 \leq n \leq 10^5$，$1 \leq T \leq 10^9$），分别表示短视频的个数和小 Q 计划刷短视频的时长。  
接下来 $n$ 行，每行两个整数 $t_i, k_i$（$1 \leq t_i, k_i \leq 10^9$），代表缓存中第 $i$ 个短视频的时长和对小 Q 的吸引力。  
*输出格式*  
输出一个整数，代表小 Q 总共看短视频的秒数。  

## D.网络改造  
小 C 有一张 $n$ 个点 $m$ 条边的有向图，点的编号依次为 $1, 2, \dots, n$，第 $i$ 条边为 $u_i \to v_i$。  
小 C 想对这个有向图进行一些改造，使得改造完毕的新图中不存在任何环。  
对于第 $i$ 条边，小 C 可以支付 $a_i$ 的代价将其反向（即变为 $v_i \to u_i$），也可以支付 $b_i$ 的代价将其删除。  
对于第 $i$ 个点，小 C 可以支付 $c_i$ 的代价将它以及所有与它相关的边一起删除。  
请写一个程序，找到总代价最小的改造方案。  
*输入格式*  
第一行包含两个正整数 $n, m$（$2 \leq n \leq 22$，$1 \leq m \leq n(n-1)$），分别表示点数和边数。  
第二行包含 $n$ 个正整数 $c_1, c_2, \dots, c_n$（$1 \leq c_i \leq 10^6$），依次表示删除每个点的代价。  
接下来 $m$ 行，每行四个正整数 $u_i, v_i, a_i, b_i$（$1 \leq u_i, v_i \leq n$，$u_i \neq v_i$，$1 \leq a_i, b_i \leq 10^6$），依次描述每条边。  
输入数据保证每对点之间每种朝向的边最多只有一条。  
*输出格式*  
输出一行一个整数，即最小的总代价。  

## E.购物计划  
小 Q 喜欢购物，双十一即将来临，某电商平台推出了“打折+满减”组合优惠方案。  
对于每个商品，商家会给出可以接受的最低折扣，买家可以选择一个折扣后的价格，再叠加平台提供的某一种满减方案获得进一步优惠。  
具体的，平台共有 $m$ 种满减方案，第 $i$ 种满减方案的方式为“每满 $a_i$ 元减 $b_i$ 元”。形式化的，假设使用该满减方案前的价格为 $x$ 元，则使用该满减方案后的价格为 $x - \left\lfloor \frac{x}{a_i} \right\rfloor b_i$ 元。  
现在小 Q 的购物车里有 $n$ 个物品，第 $i$ 个物品的原价为 $w_i$ 元，商家能够提供的最低折扣为 $\frac{p_i}{q_i}$。换言之，小 Q 可以从 $\left\lfloor \frac{p_i}{q_i} \right\rfloor$ 中选择任意实数折扣 $k$，使得物品的价格打折到 $x = w_i k$ 元（$x$ 为实数）。在此之后，小 Q 可以在打折后价格的基础上从 $m$ 种满减方案中选择一种。  
现在小 Q 想请你来帮她确定购物计划，对于每一个物品，选择一个最优的折扣+满减的组合，使得最终物品的价格尽可能低。  
*输入格式*  
第一行包含两个整数 $n, m$（$1 \leq n, m \leq 5 \times 10^5$），代表小 Q 购物车中物品的个数，和平台提供的满减方案种类数。  
接下来 $m$ 行，每行包含两个整数 $a_i, b_i$（$1 \leq b_i < a_i \leq 10^6$），代表一个满减方案。  
接下来 $n$ 行，每行包含三个整数 $w_i, p_i, q_i$（$1 \leq w_i \leq 10^6$，$1 \leq p_i \leq q_i \leq 10^6$），代表一个物品的原价，以及商家能提供的最低折扣。  
*输出格式*  
输出 $n$ 行，第 $i$ 行输出两个互质的整数 $u_i, v_i$，代表最优策略下第 $i$ 个物品的最低价为 $\frac{u_i}{v_i}$ 元。  

## F.丝之歌  
小 C 是一位幸运的《空洞骑士：丝之歌》玩家。在游戏中，玩家扮演致命猎手“大黄蜂”，踏入丝与歌统治的王国。被俘至陌生世界，在致命的朝圣之路上迎战强敌，破解远古谜团，直抵王国巅峰。作为一位老空洞玩家，小 C 自从丝之歌发售以来就没日没夜地乐在其中。但不知道是因为手感生疏还是这一作难度加强，他发现自己在这一作中经常死亡，于是小 C 决定对游戏难度进行深入研究。  
游戏中核心的货币系统以“念珠”为单位，绝大部分商品都需要使用念珠购买。但遗憾的是，玩家死亡时全部的念珠会丢失，无法找回。但游戏支持提供“念珠串”机制——玩家可以在商人处把若干念珠兑换成念珠串，念珠串在玩家死亡时不会消失，在玩家重生后依然存在。具体的，如果玩家当前拥有的念珠不少于 $a$ 个，那么他可以消耗 $a$ 个念珠兑换一个念珠串。在一个商人处玩家可以兑换任意数量的念珠串，只要符合兑换的要求。此外，在任意时刻玩家都可以选择拆解念珠串。每拆解一个念珠串可以使得当前的念珠数量增加 $b$（$b \leq a$），同时该念珠串消失。  
游戏中玩家的生命值以“面具”为单位。在满血状态下玩家拥有 $c$ 个面具，当玩家的面具数变为 0 时玩家死亡，会直接回到最近的复活点复活，并回到满血状态。游戏中只有复活点处可以回复血量。  
游戏中共有 $m$ 种不同类型的敌人。在面对类型为 $i$ 的敌人时，小 C 对于战斗的结果用一个下三角矩阵 $P_i$ 刻画：$P_{i,x,y} (1 \leq x \leq c, 0 \leq y \leq z)$ 代表小 C 在与一个类型为 $i$ 的敌人战斗前有 $x$ 个面具，战斗后有 $y$ 个面具的概率。特殊的，$y = 0$ 代表小 C 战斗后死亡。如果小 C 没有战斗后死亡，则代表小 C 击杀了该敌人，将会获得 $w_i$ 个念珠。  
为了简化模型，小 C 把游戏抽象成线性设计：游戏共有 $n$ 个关卡，他需要按照关卡编号从小到大依次通过。每个关卡由三部分构成：复活点、敌人、商人。在关卡开始时玩家会先经过复活点，并把血量回复至满血状态。然后玩家要依次面对若干个敌人。如果小 C 在挑战某个敌人时死亡，则会按照上述规则回到该关卡的复活点，再重新一次挑战所有敌人（该关卡内此前击败的敌人会重置回初始状态）。如果小 C 顺利击杀该关卡内全部敌人，则可以顺利来到商人处合成念珠串或购买商品，并进入下一关。  
小 C 知道自己现在的游戏水平不佳，因此除了第 $n$ 个关卡的商人处，每次他来到商人处都会尽可能的把手头的念珠兑换成念珠串，直到手头的念珠数量小于 $a$。  
小 C 认为来到第 $n$ 个关卡的商人处视为游戏通关，并且他会在第 $n$ 个关卡的商人处拆解此前兑换的全部念珠串。他想知道在这样的模型假设下，他通关时拥有的念珠期望个数是多少？答案对 998244353 取模。  
注：题面中描述的若干机制和现实中该游戏机制略有出入，请以题面描述为准。  
*输入格式*  
第一行包含五个整数 $n, m, a, b, c$（$1 \leq n, m, a, b \leq 10^3$，$b \leq a$，$1 \leq c \leq 10$），代表游戏的关卡数、敌人的种类数、兑换一个念珠串所需的念珠数、拆解一个念珠串可以获得的念珠数、满血状态下玩家的面具数。  
第二行包含 $m$ 个整数 $w_1, w_2, \cdots, w_i$（$1 \leq w_i \leq 10^6$），其中 $w_i$ 代表击杀第 $i$ 类敌人能获得的念珠数量。  
接下来 $n$ 行，每行描述一个关卡的信息：  
- 每行开头为一个整数 $t_i$（$1 \leq t_i \leq 100$），代表这一个关卡中有多少次敌人。  
- 接下来 $2t_i$ 个整数 $ty_{i,1}, num_{i,1}, ty_{i,2}, num_{i,2}, \cdots, ty_{i,t}$（$1 \leq ty_{i,j} \leq m$，$1 \leq num_{i,j} \leq 10^9$），代表第 $i$ 个关卡的敌人共有 $\sum_{1 \leq j < i} num_{i,j}$ 个，依次为：$num_{i,1}$ 个种类为 $ty_{i,1}$ 的敌人，$num_{i,2}$ 个种类为 $ty_{i,2}$ 的敌人，以此类推。注意玩家会依次挑战这些敌人，每次只会面对一个敌人。  
*输出格式*  
输出一行一个整数，代表小 C 通关时期望拥有的念珠个数。    

## G.最大公约数  
如果数 $a$ 能被数 $b$ 整除，$b$ 就叫做 $a$ 的约数。两个整数公有的约数，叫做这两个数的公约数，其中最大的一个叫做这两个数的最大公约数。例如：12、16 的公约数有 1、2、4，其中最大的一个是 4，4 是 12 与 16 的最大公约数，一般记为 $\gcd(12, 16) = 4$。  
现在小 C 给你两个正整数 $n, k$，请从 $[1, n]$ 中选出恰好 $k$ 个互不相同的正整数 $x_1, x_2, \dots, x_k$，使得 $\gcd(x_i, x_j) = 1$ 对于任意整数对 $(i, j)$ 恒成立，其中 $1 \leq i < j \leq k$，或判断无解。  
*输入格式*  
输入一行，包含两个正整数 $n, k$（$2 \leq k \leq n \leq 3 \times 10^5$）。  
*输出格式*  
如果存在可行方案，输出两行，第一行输出 YES，第二行输出 $k$ 个 $[1, n]$ 内的互不相同的正整数 $x_1, x_2, \dots, x_k$。如果有多组可行方案，输出任意一组。  
如果不存在可行方案，输出一行 NO。 

## H.缺陷解码器  
有一个字符串 $S$，一开始它是空串。现在有一个带有缺陷的解码器正在不断吐出字符添加至字符串 $S$ 的末尾。本题中字符集的大小为 $m$，每次解码器会以每种字符 $\frac{1}{m}$ 的概率等概率随机吐出一个新字符添加至 $S$ 的末尾。  
由于解码器具有缺陷，每次吐出一个字符后，它会审视当前的字符串 $S$ 是否稳定。解码器认为字符串 $S$ 是不稳定的当且仅当 $S$ 是长度至少为 2 的回文串，或者它能写成 $S = U + U$ 或者 $S = U + v + U$ 的形式，其中 $U$ 是任意非空字符串，$v$ 是任意单个字符。例如，**abcabc**、**ababa** 和 **abcabc** 都是不稳定的，但是任意长度为 1 的字符串都是稳定的。如果当前的字符串 $S$ 不稳定，解码器就会重置 $S$ 为空串。  
请写一个程序，计算解码器期望吐出多少个字符后才能得到一个稳定的长度恰好为 $n$ 的字符串 $S$，或判断永远不可能实现。请注意，即使在吐字的过程中反复重置了字符串，也不会清零历史吐字次数的统计，例如 **a → ab → aba → (空串) → a → ab → abc →** 共吐出了 6 个字符。  
*输入格式*  
包含一行两个正整数 $n, m$（$1 \leq n \leq 12$，$1 \leq m \leq 10^9$）。  
*输出格式*   
输出一行一个整数，即期望吐字数。  
若永远不可能实现，输出 **-1**，否则假设答案是 $\frac{p}{q}$，你需要输出最小的非负整数 $r$ 满足 $q \cdot r \equiv p \pmod{(10^9 + 7)}$。你可以认为这样的 $r$ 一定存在。  

## I.五子连珠  
小 C 和小 Q 最近在玩五子连珠，只要某一方的棋子不少于 5 个连续出现在同一行，或同一列，或同一 45 度斜线（左上到右下，或右上到左下）即视为胜利。  
但小 C 和小 Q 太沉迷下棋了，他们甚至没有注意到某一方可能已经胜利了。你可以写一个程序，帮助他们来判断谁获胜了吗？  
*输入格式*   
第一行一个整数 $n$（$5 \leq n \leq 10$），代表棋盘的大小为 $n$ 行 $n$ 列。  
接下来 $n$ 行，每行 $n$ 个字符。第 $i$ 行的第 $j$ 个字符代表棋盘上第 $i$ 行第 $j$ 列的情况。具体的，每个字符只会是如下三种之一：  
- `·`：这个位置上没有棋子  
- `c`：这个位置上有一个小 C 的棋子  
- `Q`：这个位置上有一个小 Q 的棋子  
*输出格式*  
输出一行一个字符串，代表结果。  
如果此时没有任何人获胜，输出 **No winner till now**。  
如果此时小 C 满足胜利条件，但小 Q 没有满足胜利条件，输出 **The winner is little C**。  
如果此时小 Q 满足胜利条件，但小 C 没有满足胜利条件，输出 **The winner is little Q**。  
如果此时双方都满足胜利条件，输出 **Too late to know who the winner is**。  

## J.后鼻嘤  
由于经常忘记一个字的读音是前鼻音还是后鼻音，小 Q 决定把所有区分不出前后鼻音的拼音都读成后鼻音！例如，“后鼻音”这个词小 Q 会读成发音和“后鼻唛”一致。  
具体的，如果一个拼音为 **n** 或 **ng** 结尾，小 Q 都会把这个拼音发成以 **ng** 结尾。  
现在给定一句话每个字正确的拼音，请你输出小 Q 会如何读出这句话。  
*输入格式*  
输入一行包括若干个小写字符串，用单个空格分隔，第 $i$ 个小写字符串代表这句话第 $i$ 个字的拼音。  
数据保证每个字符串的长度不小于 2 且不超过 6。字符串的数量不超过 1000。  
*输出格式*

形式化的，给定一列包含 $n$ 个节点的有根树 $T$，节点编号为 $1, 2, \cdots, n$，其中 1 号节点为根节点。我们会通过如下表示法将其转化为一棵同样包含 $n$ 个节点的以 1 号节点为根的二叉树 $T'$：  
对于树上的每个节点 $u$，假设其儿子节点的编号依次为 $v_1, v_2, \cdots, v_k$。  
- 你可以对这些儿子节点指定任意顺序，假设为 $v'_1, v'_2, \cdots, v'_k$。  
- 在树 $T'$ 中，节点 $u$ 的左儿子为 $v'_1$；对于任意 $i \in [1, k-1]$，节点 $v'_i$ 的右儿子为 $v'_{i+1}$。  
我们定义两棵二叉树不同，当且仅当存在一个节点 $u$，在两棵树中 $u$ 的左儿子节点编号不同（或其中一个有左儿子，一个没有），或在两棵树中 $u$ 的右儿子节点编号不同（或其中一个有右儿子，一个没有）。我们定义一个节点的子树大小为其子树的节点个数（包括它本身）。  
小 C 注意到，在这样的表示法下，最终的树 $T'$ 的形态有很多种可能。

第一行一个整数 $n$（$1 \leq n \leq 10^5$），代表树上的节点个数。  
第二行 $n-1$ 个整数 $f_2, f_3, \cdots, f_n$（$1 \leq f_i < i$），其中 $f_i$ 表示节点 $i$ 的父节点编号。  
*输出格式*   
输出两行，每行一个整数。

第二行的整数代表“好表示”的 $T'$ 的个数，对 998244353 取模。

### B.爬山
**Tag**: 最短路，分层图技巧  
> 给定一个无向有权图，每个节点 $i$ 还有一个高度 $h_i$。从 $1$ 号点出发，初始疲劳为 $0$。对于一条边 $u \to v$：如果 $h_u > h_v$ 则疲劳清空；否则积累 $h_v - h_u$。在最大疲劳不超过 $H$ 的前提下，求到每个点的最短路。  
考虑建立 $H + 1$ 层的分层图（从 $0$ 到 $H$），其中第 $i$ 层代表当前的疲劳为 $i$。  
考虑第 $i$ 层的节点 $u$，对于一条边 $u \to v$：  
- 如果 $h_u > h_v$，连接一条到第 $0$ 层节点 $v$ 的边；  
- 否则，如果 $i + h_v - h_u > H$ 则忽略；否则连接一条到第 $i + h_v - h_u$ 层节点 $v$ 的边。  
跑最短路即可。复杂度 $\mathcal{O}((n + m)H \log((n + m)H))$。
### E.购物计划
**Tag**: 数据结构  
> 平台共有 $m$ 种满减方案，第 $i$ 种满减方案的方式为“每满 $a_i$ 元减 $b_i$ 元”。现在有 $n$ 个物品，第 $i$ 个物品的原价为 $w_i$ 元，从 $\left[\frac{p_i}{q_i}, 1\right]$ 中选择任意实数折扣 $k$，使得物品的价格打折到 $x = w_i k$ 元（$x$ 为实数）。然后在打折后价格的基础上从 $m$ 种满减方案中选择一种。对每一个物品，选择最优的折扣+满减的组合，最小化最终价格。  
设 $f_j(x) = x - \left\lfloor \frac{x}{a_i} \right\rfloor b_i$，相当于查询 $\min_{k \in [\frac{p_i}{q_i}, 1]} \min_{j \in [1, m]} f_j(w_i k)$。观察到所有 $f_j$ 都是一段 45 度斜线 + 在 $a_i$ 倍数处骤减 $b_i$ 的形式，因此只需要重点关注每一个 $a_i$ 的倍数处价格，即可快速处理每一个整点的最小价格。此处复杂度为 $\mathcal{O}(w \log w)$。  
再注意到最小值的 $k$ 只会取在 $\frac{p_i}{q_i}$ 处，或更大但价格为整数的地方。而且 $k = \frac{p_i}{q_i}$ 时选择的最优满减方案一定是 $\left\lfloor \frac{p_i w_i}{q_i} \right\rfloor$ 这一整点对应的最小价格的满减方案。只需要单点查询+后缀最小值查询。使用线段树或其他数据结构即可 $\mathcal{O}((n + w) \log w)$ 解决此题。注意分数类运算需要分子分母互质，以及运算过程中可能爆 `int` 的问题。
### D.网络改造
**Tag**: 状压 DP，拓扑序  
> 给定一张 $n$ 个点 $m$ 条边的有向图。第 $i$ 条边可以支付 $a_i$ 将其反向，也可以支付 $b_i$ 将其删除。第 $i$ 个点可以支付 $c_i$ 将它以及所有与它相关的边一起删除。求最小总代价，使得改造完毕的新图中不存在任何环。  
首先忽略删点的操作。  
因为改造完毕的图没有环，所以存在一个拓扑序 $p_1 \to p_2 \to \cdots \to p_n$ 满足任意一条边都是 $p_i \to p_j$ 的形式，其中 $i < j$。固定一种拓扑序，那么对于每条违背该拓扑序的边，必须要删除或者反向，这说明这条边的最优改造代价是两者的较小值。  
设 $f[S]$ 表示点集 $S$ 所有可能的拓扑序中改造总代价的最小值。枚举 $S$ 中拓扑序最大的点 $x$，则  
$$f[S] = \min_{x \in S} \{ f[S \setminus x] + w[x][S \setminus x] \}$$  
其中 $w[x][S]$ 表示 $x$ 连向点集 $S$ 中的所有边的改造代价之和。令 $y$ 为 $S$ 中任意一个点，则  
$$w[x][S] = w[x][S \setminus y] + \min\{ a_{x \to y}, b_{x \to y} \}$$  
$f[\cdot]$ 和 $w[\cdot][\cdot]$ 都可以在 $\mathcal{O}(n 2^n)$ 的时间内求出。  
最后再加入删点操作，令 $g[S]$ 表示点集 $S$ 中所有点的删除代价之和，设 $A$ 为全集。那么  
$$ans = \min_S \{ f[S] + g[A \setminus S] \}$$
### H.缺陷解码器
**Tag**: 回文，期望 DP  
> 解码器随机生成字符，若当前字符串是长度 $\ge 2$ 的回文、$U + U$ 或 $U + v + U$ 的形式则重置为空。求得到稳定长度为 $n$ 的期望吐字次数。  
设 $E(S)$ 表示当前字符串是 $S$ 时，期望再吐出多少个字符才能得到一个稳定的长度恰好为 $n$ 的字符串：  
- 若 $S$ 不稳定，则 $E(S) = E( \text{空串} )$；  
- 若 $S$ 稳定且 $|S| = n$，则 $E(S) = 0$；  
- 若 $S$ 稳定且 $|S| < n$，则 $E(S) = \frac{\sum_{c=1}^{m} E(S + \text{char}(c))}{m} + 1$。  
如果从空串出发无法接触到任一稳定且串长为 $n$ 的状态，则无解。  
因为第一种情况的存在，这个期望递推有环。设 $E(S) = a[S] \cdot E(\text{空串}) + b[S]$，则：  
- 若 $S$ 不稳定，则 $a[S]=1, b[S]=0$；  
- 若 $S$ 稳定且 $|S|=n$，则 $a[S]=0, b[S]=0$；  
- 若 $S$ 稳定且 $|S|<n$，则 $a[S] = \frac{\sum_{c=1}^{m} a[S + \text{char}(c)]}{m}$，$b[S] = \frac{\sum_{c=1}^{m} b[S + \text{char}(c)]}{m} + 1$。  
此时递推不再有环，计算出 $a[\text{空串}]$ 和 $b[\text{空串}]$ 后根据 $E(\text{空串}) = a[\text{空串}] \cdot E(\text{空串}) + b[\text{空串}]$ 即可解出答案。  
注意将 $S$ 中的字符按照从左往右第一次出现的顺序重新编号成 $1,2,3,\dots$ 不影响字符串稳定与否的判断，所以设 $r$ 表示 $S$ 中最大的字符，则第三种递推等价于  
$$E(S) = \frac{\sum_{c=1}^{r} E(S + \text{char}(c)) + (m-r) E(S + \text{char}(r+1))}{m} + 1$$  
此时 $S$ 的状态数为 $\sum_{i=1}^{n} \text{Bell}(i) \approx 5 \times 10^6$，可以接受。
### F.丝之歌
**Tag**: 期望 DP，矩阵快速幂  
> 给定一系列规则，计算全部关卡通关后期望货币数量。注意到每个关卡只需要区分一次通关和非一次通关两种情况，假设一次通关的概率为 $p$。  
令 $dp[i][j]$ 表示经过了前 $i$ 关，手中剩余念珠数量为 $j$ 的概率。转移枚举是否一次通关，即可知道最终手中的念珠数量。对于兑换成念珠串的部分，由于一定会贡献到最终答案，可以在转移时直接加到最终答案中。注意最后一次通关不需要把念珠合成念珠串。此部分复杂度为 $\mathcal{O}(n a)$。  
关于计算每一关通关的概率，注意到其实是相应的概率矩阵连乘积后 $[c][0]$ 处的值。因此可以通过矩阵快速幂计算。但直接使用矩阵快速幂复杂度为 $\mathcal{O}(n t c^3 \log \text{num})$ 无法通过。  
考虑 $\mathcal{O}(m c^3 \log \text{num})$ 预处理每个敌人的概率矩阵的 2 的幂次。计算答案时由于只关注最终结果的 $[c][0]$ 处这一个位置，我们可以使用 $\mathcal{O}(c^2)$ 的矩阵乘向量，而不是 $\mathcal{O}(c^3)$ 的矩阵乘法。  
最终复杂度 $\mathcal{O}(n a + m c^3 \log \text{num} + n t c^2 \log \text{num})$。  
此外也存在一些常数优化的方法：  
- 转移矩阵为下三角矩阵，下三角矩阵乘以下三角矩阵还是下三角矩阵。因此矩阵乘法枚举的时候可以只枚举 $i \ge j \ge k$，获得 $1/6$ 的常数。  
- 注意到 $c$ 最大为 11，因此矩阵乘法每个位置的值不会超过 $998244353^2 \times 11 < 2^{64}$，因此可以使用 `unsigned long long` 存储结果，只进行一次取模。
