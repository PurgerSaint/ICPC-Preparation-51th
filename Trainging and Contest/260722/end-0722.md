## 题目详情
On an infinite number line, at point $0$, sits a frog. After many years of meditation, the frog has mastered $n$ unique types of magical jumps. The $i$\-th type of jump allows it to jump forward by no more than $a_i$ units. In other words, if it was at integer point $k$, after the jump it can land **at any integer point from $k$ to $k+a_i$**.
But magic always comes with a price; it has been cursed. Before each $b_i$\-th attempt (before $b_i$\-th, $2b_i$\-th, $3b_i$\-th etc. attempt among the jumps of type $i$) to use the $i$\-th type of jump, the frog rolls back $c_i$ units! In other words, if it was at point $k$, it will first find itself at point $k-c_i$, and after the jump, it can land at any integer point from $k-c_i$ to $k-c_i+a_i$.
The frog's goal is to reach the point with the number $x$, using jumps while minimizing the number of rollbacks. Help the frog — find the minimum number of rollbacks it will have to endure on its way to the goal, or determine that it cannot reach point $x$.
> $1<=t<=10^4, 1<=n<=10^5, 1<=x<=10^18, 1<=a_{i},b_{i},c_{i}<=10^6$
## 提交详情
- 提交时间:17:34 状态:WA 详细状态:`Wrong answer on test 2`
> 对每一个 $a,b,c$ 都有一个最大位置`mx_step`和完整位置`full_step`  
最大位置即在第 $b-1$ 步时可以到达的位置，完整位置即在第 $b$ 步时到达的位置  
如果 $x$ 在最大位置之内，即不会经历翻滚可以到达 $x$ ,此时直接返回0即可  
如果完整位置小于或等于0，即后续要么原地不动，要么后退，而上述情况已包含，那么此时代表目标不可达  
对于 $x=7,a=4,b=2,c=5$ ,第一步可以到达最大位置4，第二步可以到达完整位置3  
这个例子是第三步到达的，即第三步跨越4步从3到达 $x=7$  
那么对于每一个 $a,b,c$ ,都可以先假设当前在 $x$ 的最大位置之前 $x-mx_step$ ,然后剩余的看需要多少个完整步数即可到达  
这里的完整步数个数就是回滚次数，不存在不会滚到达最大位置之后的位置
- 提交时间:17:34 状态:WA 详细状态:`Wrong answer on test 2`
> 经*GPT*指导后，我发现我犯了一个错误:到达 $x$ 是由多种跳跃方式组成的，而非单一方式到达  
那么到达 $x$ 可以看作若干个完整位置(由某种方式组成的)加上一个或没有的最大位置  
要使得回滚次数最少，那么就使得完整位置和最大位置最大化即可  
那我就找到所给跳跃方式中，最大位置和完整位置最大的，按之前的方法计算即可  
- 提交时间:18:44 状态:AC 详细状态:`-`
> 我发现我之前脑子错乱了，我一直在想着，最大位置就是所有方式都使用完免费次数后的最大位置  
然后选一个净位移最大的方式实现回滚，加上免费位置（最大位置）就是完整位置，之后再加免费位置后再回滚  
但这里不对，之后再用免费位置，就会触发其他方式的回滚，造成回滚次数更大了  
故完整位置，即最大位置后的每次完整位置（步数），应该是所有方式中 $a*b-c$ 最大的那个  
因为这样，才能使得`最大位置`和后续每次`完整位置`的最大化，使得总回滚次数最小化

There are $n$ children standing in a line, where the niceness of the $i$\-th child is $a_i$. Santa is deciding which children belong on the nice list and which belong on the naughty list.
An integer $X$ is initially set to $0$. Santa will perform the following operation **exactly** $n-1$ times:
-   Choose the first or second child in line and remove them from the line.
-   Let $w$ be the niceness of the chosen child.
    -   If the first child was chosen, add them to the nice list and add $w$ to $X$.
    -   If the second child was chosen, add them to the naughty list and subtract $w$ from $X$.
Note that after all operations, exactly one child remains unassigned to a list.
Determine the maximum possible value of $X$ that Santa can obtain after all $n-1$ operations.
> $1<=t<=10^4, 2<=n<=2\times 10^5, -10^9<=a_{i}<=10^9$
## 思考
> 我根据题意进行了手动模拟，即根据第一个和负的第二个进行选择  
题目貌似有深意，即不像我这样真正去模拟题意，真正去做到每次最优  
而是可以部分选非最优的，其余的选最优使得最大化
然后我尝试去锁定某一个，对于当前锁定后的元素，计算负的后缀和  
对于锁定前的元素，按之前的手动模拟方法局部贪心即可
## 提交详情
- 提交时间: 状态:AC 详细状态:`-`
> 经*GPT*指导下，我的方法枚举留下来的那个是对的  
但后缀可以不用后缀和数组，用一个变量即可  
对于该元素的前缀，可以计算他们的绝对值总和  
因为有以下情况:
> 1. 正数 正数:自然先加第一个正数
> 2. 正数 负数:自然先处理第二个负数
> 3. 负数 负数
> 4. 负数 正数
> 注意情况3和情况4，这种情况下需要单独处理 $a_{0}$  
即如果第二个元素及以后元素是负数，都能通过情况2进行处理  
故前缀和是第一个元素加上后续到锁定元素前每个元素的绝对值之和

# 力扣509. 斐波那契数
[Rating]简单
## 题目详情
斐波那契数 （通常用 F(n) 表示）形成的序列称为 斐波那契数列 。该数列由 0 和 1 开始，后面的每一项数字都是前面两项数字的和。也就是：
F(0) = 0，F(1) = 1
F(n) = F(n - 1) + F(n - 2)，其中 n > 1
给定 n ，请计算 F(n) 。
> $0<=n<=30$
## 提交详情
- 提交时间:22:28 状态:通过
> 定义 $dp_{i}$ 为斐波那契数的第 $i$ 项, 状态转移为 $dp_{i}=dp_{i-1}+dp_{i-2}$  
其中存在初始化 $dp_{0}=0,dp_{1}=1$

给你一个整数数组 nums ，找到其中最长严格递增子序列的长度。
子序列 是由数组派生而来的序列，删除（或不删除）数组中的元素而不改变其余元素的顺序。例如，[3,6,2,7] 是数组 [0,3,1,6,2,2,7] 的子序列。
> $1 <= nums.length <= 2500, -10^4 <= nums[i] <= 10^4$
## 思考
> 我一开始只用最简单的dp递推:`dp[i] = max(dp[i - 1], dp[i - 1] + (nums[i] > nums[i - 1]));`  
但这是错的，因为要严格递增，这样的话就会失去大小关系  
应该是像我之前笔记里的那样，往前再次枚举，寻找比他小的再处理:`dp[i] = max(dp[i], dp[j] + 1);`,最后输出最大值即可  
然后我再温习了笔记里的牌堆法，枚举每个数，如果当前牌堆为空，或当前数比牌堆第一张牌大，就将当前数放到牌堆顶，否则就二分搜索其中的牌，并进行替换
