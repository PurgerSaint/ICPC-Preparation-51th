## 题目详情
小 C 喜欢爬山，但他的体能一般，不能连续爬升太高。
这天小 C 决定去爬比特峰。比特峰共有 $n$ 个景点，第 $i$ 个景点的海拔为 $h_i$ 米。
景点之间共有 $m$ 条双向线路，第 $i$ 条线路连通景点 $u_i$ 和景点 $v_i$ ，小 C 从任意方向走过第 $i$ 条线路所需的时长均为 $t_i$ 分钟。
小 C 在爬山过程中会累积疲劳值，初始的疲劳值为 $0$ ，并且小 C 能够忍受的最大疲劳值为 $H$ 。
假设当前小 C 位于某个景点 $x$，且存在一条从景点 $x$ 到景点 $y$ 的线路：
+ 如果景点 $x$ 比景点 $y$ 的海拔高，那么这是一段轻松的下坡路，小 C 如果选择走这条线路，体力得到了恢复，疲劳值被清空。
+ 否则，如果小 C 选择走这条线路，疲劳值会累积 $h_y-h_x$ 。小 C 只能在保证积累的疲劳值不超过 $H$ 的前提下走这条线路。
现在小 C 从 $1$ 号景点出发，只能通过这些线路在景点间移动。对于每个景点，小 C 想知道他最快需要多少分钟可以到达该景点，或永远无法到达？
*输入格式*

第二行包含 $n$ 个正整数 $h_1,h_2,\cdots,h_n~(1\le h_i\le 10^9)$，代表每个景点的海拔。
接下来 $m$ 行，每行三个正整数 $u_i,v_i,t_i~(1\le u_i,v_i\le n,u_i\ne v_i,1\le t_i\le 10^9)$ ，代表一条线路连接的两个景点和所需的时长。
*输出格式*
输出一行 $n-1$ 个整数，第 $i$ 个整数代表小 C 到达第 $i+1$ 号景点所需的最短时间（以分钟为单位）。如果小 C 永远无法到达该景点，输出 `-1` 。

## 题目详情
Given a binary cyclic sequence $$S$$ of length $$n$$, whose elements are either $$0$$ or $$1$$, you can do the following operation any number of times.
-   **Operation**: if the length of $$S$$ is greater than or equal to $$3$$, choose a position $$i$$ ($$1\le i\le n$$) such that $$S_i=1$$, remove the element on position $$i$$ and both its adjacent elements (remove $$3$$ elements in total), and do not change the relative order of the other elements. Note that elements in the first and last positions are considered adjacent.
A binary cyclic sequence $$S$$ is called *good* if you can make $$S$$ empty using the operation above.
And the *beauty* of a binary cyclic sequence $$S$$, $$f(S)$$, is defined as the minimum number of modifications needed to make $$S$$ good. In a single modification you can flip an arbitrary element in $$S$$, that is, $$0$$ becomes $$1$$ and $$1$$ becomes $$0$$.
Given are a binary string $$a$$ of length $$n$$ and $$q$$ queries. For the $$i$$-th query you are given two integers $$l_i$$ and $$r_i$$, and you should answer $$f(a_{l_i..r_i})$$ (where we consider the substring $$a_{l_i..r_i}$$ as a cyclic sequence).
*输入格式*
The first line contains two integers $$n$$ and $$q$$ ($$3\le n\le 10^6$$, $$1\le q\le 10^6$$) — the length of string $$a$$ and the number of queries, respectively.
The second line contains the string $$a_1a_2\cdots a_n$$, where each $$a_i$$ is either $$0$$ or $$1$$.
Each of the following $$q$$ lines contains two integers $$l_i$$ and $$r_i$$ ($$1\le l_i\le r_i\le n$$, $$(r_i-l_i+1)\equiv 0\mod 3$$) describing the $$i$$-th query.
*输出格式*
Output $$q$$ lines, where the $$i$$-th line contains a single integer — the answer for the $$i$$-th query.

经*Gemini*咨询下，我的以下问题被解决了，他是把1比喻成炸弹：
> 问题1: 任何长度的连续炸弹序列，得到的贡献至多是左右两个炸弹。那其中的包含的炸弹，不对串中其他的0产生影响啊？  
答：设存在`0 0 0 [ 1₁ 1₂ 1₃ 1₄ 1₅ 1₆ ]`，`1₁`会炸掉左边的0和右边的`1₂`，`1₃`会炸掉左边的0和右边的`1₄`  
`1₅`会炸掉左边的0和右边的`1₆` ，即在这个连续的炸弹序列中，奇数位置的炸弹会带走左侧的一个0和右侧偶数位置的炸弹  
故一个连续的炸弹序列，其长度为`L`，会带来`L/2`(向下取整)的效果，即其中`L/2`(向下取整)的炸弹是有效的  
> 对于任何一个序列，需要的炸弹数是总长度的`1/3`  
队友的思路是先计算总需要的炸弹数，然后统计原串的连续炸弹能提供的有效炸弹数，再计算补齐量就能找到答案  
> 问题2: 总长度除以三是总需要的炸弹数量，但这个总长度包含了连续炸弹的数量啊。为什么不是单独拎出0，计算0的总长度，再计算总需要的炸弹数啊？  
答: 据上面所知，每个连续炸弹中的每个炸弹也会受影响，也会需要被删除，无法被排除单独计算  
> 问题3: 我感觉我还是模拟的思想，去单独拎出来0序列，然后删除能被1影响的0（即按之前炸弹能炸掉的0，通过模拟），然后再对剩下的0进行计算取需要的差值。这样模拟的思想难于如何删除被炸弹炸掉的0，是吗？
答: 如果这样真去模拟，会遇到两个问题。第一个问题是会遇到模拟下最优方法的选择，即当前不同的选择带来的代价不同，无法判断每个选择是真最优解；第二个问题是炸掉中间的字符后，左右两侧的字符会相连到一起，不论单次相邻的模拟，而是如果这题真模拟，这样相邻的次数必然只多不少，且结合第一个最优解的问题，极难实现且去维护。故这两者结合起来，去模拟追寻0这个动态变量，极难实现  
队友的思路是基于这个公式`最小翻转次数=max(0, k-mis)`  
`k`是这个串需要的最少炸弹数；`mis`为这个串首尾相连后，已有炸弹中的有效炸弹数  
然后得到每一段连续炸弹的左右边界，再计算每一连续炸弹的贡献(即有效炸弹数)  
为了避免每个区间内重复统计有效炸弹数，故而引入了前缀和，能快速得到目标区间内有效的炸弹数  
> 问题3: 前缀和是否不能精准计算出含有残缺连续炸弹序列的有效炸弹数?  
答: 由于队友是分段算法，即将当前段分为左侧段、中间连续炸弹序列段(包含完整若干炸弹序列)、右侧段  
中间段能通过前缀和得到准确的有效炸弹数量  
而左右段能通过下标计算得到有效的炸弹数量  
故而能得到准确需要的差值，最后队友还通过环形检查进行了炸弹优化
