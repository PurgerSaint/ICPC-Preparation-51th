# C.Between P and Q
## 题目详情
You are given an integer $N$ and integer sequences $P=(P_1,P_2,\ldots, P_N)$ and $Q=(Q_1,Q_2,\ldots,Q_N)$, each of which is a permutation of $(1,2,\ldots,N)$.
Find the number of integer sequences that are a permutation of $(1,2,\ldots,N)$ and are lexicographically greater than $P$ and lexicographically less than $Q$.
What is lexicographic order for integer sequences?
For integer sequences $S = (S_1,S_2,\ldots,S_{|S|})$ and $T = (T_1,T_2,\ldots,T_{|T|})$, we say that $S$ is **lexicographically smaller** than $T$ if $1.$ or $2.$ below holds. Here, $|S|, |T|$ denote the lengths of $S, T$, respectively.
1.  $|S| \lt |T|$ and $(S_1,S_2,\ldots,S_{|S|}) = (T_1,T_2,\ldots,T_{|S|})$.
2.  There exists an integer $1 \leq i \leq \min\lbrace |S|, |T| \rbrace$ such that both of the following two conditions hold.
    -   $(S_1,S_2,\ldots,S_{i-1}) = (T_1,T_2,\ldots,T_{i-1})$
    -   $S_i$ is (numerically) smaller than $T_i$.
> $1<=N<=10$
## 思考
> 我想的是寻找所有确定性元素(即`P[i]`小于`Q[i]`)，设 $L$ 为确定性元素个数  
即 $L$ 为可动元素数量  
从前往后枚举每一个确定性元素，设 $cnt$ 为已枚举过的确定性元素  
每一个确定性元素的取值范围包括三个情况:
> 1. 当前取值 $t$ 满足 $P_{i}<t<Q_{i}$ ,后续确定性元素的数字可任选, 当前值的的方案数为 $n-L-1-cnt$ 的阶乘  
> 2. 当前取值 $t$ 等于`P[i]`或`Q[i]`，就要引入下一个不确定元素 $g$ 了, 必须使得 $P_{j}<g<Q_{j}$  
> 但是这样实现起来还是麻烦，唯一想到优化的方法，就是根据每个确定性元素决定  
只要当前这个确定性元素能够取得 $t$ 满足 $P_{i}<t<Q_{i}$ ,后续就随便排了，得到初步答案 $ans=(Q_{i}-P_{i}-1)*!(n-L-1-cnt)$  
然后根据之前已枚举的确定性元素的边界情况(`t`为`P[i]`或`Q[i]`)，再将`ans`乘以 $2^{cnt}$  
但这样又有新问题，之前已枚举确定性元素的边界无法确定其是否在取值范围内 $(P_{i},Q_{i}]$  
然后就是我能力的问题了，在于不在，在组合数学中的判断更加困难

```cpp
vector<vector<int>> ans;
int rank_p = -1, rank_q = -1;
vector<int> p, q;
int n;
void dfs(vector<int> path, string s) {
    if ((int)path.size() == n) {
        if (path == p) rank_p = ans.size();
        else if (path == q) rank_q = ans.size();
        ans.push_back(path);
        return;
    }
    for (int i = 1; i <= n; i++) {
        if (s[i - 1] == '1') continue;
        s[i - 1] = '1';
        path.push_back(i);
        dfs(path, s);
        s[i - 1] = '0';
        path.pop_back();
    }
}

int main() {
    ios;
    cin >> n;
    p = vector<int>(n);
    q = vector<int>(n);
    for (int& t: p) cin >> t;
    for (int& t: q) cin >> t;
    string s(10, '0');
    for (int i = 1; i <= n; i++) {
        s[i - 1] = '1';
        dfs({i}, s);
        s[i - 1] = '0';
    }
    cout << max(0, rank_q - rank_p - 1);
    return 0;
}
```

# E.Sum of Average
[Time]思考+理解21:49，补题01:17:00
## 题目详情
You are given a positive integer $N$ and a length-$N$ integer sequence $A=(A_1,A_2,\ldots,A_N)$.
Define $f(l,r)$ as the (arithmetic) mean of $A_l,A_{l+1},\ldots,A_r$.
Find $\displaystyle \sum_{1\le l\le r\le N} f(l,r)$, modulo $998244353$.
Definition of a rational number modulo $998244353$
Under the constraints of this problem, it can be proved that the rational number to be found is always an irreducible fraction $\frac{P}{Q}$ such that $Q {{}\not\equiv{}} 0 \pmod{998244353}$. Thus, there is a unique integer $R$ such that $R \times Q \equiv P \pmod{998244353}, 0 \leq R < 998244353$. Output this $R$.
> $1<=N<=5\times 10^5, 0<=A_{i}<998244353$
## 提交详情
- 提交时间:(07/26)01:27:32 状态:AC 详细状态:`-`
> 以下经*GPT*推导而出  
> 1. 展开公式  
> 子数组 $[l,r]$ 的平均值是 $f(l,r)=\frac{A_{l}+A_{l+1}+\dots+A_{r}}{r-l+1}$  
而题目要求 $\displaystyle \sum_{1\le l\le r\le N}^{} f(l,r)=\sum_{1\le l\le r\le N}^{} \frac{A_{l}+A_{l+1}+\dots+A_{r}}{r-l+1}$  
展开得到 $\sum_{l\le r}^{} (\frac{A_{l}}{r-l+1}+\frac{A_{l+1}}{r-l+1}+\dots+\frac{A_{r}}{r-l+1})$  
那么题目就从`每个子数组的贡献`转移到`每个元素的贡献`
> 2. 优化式子   
对于每个 $A_{i}(l\le i\le r)$ ,即 $\frac{A_{i}}{r-l+1}$  
可得到 $A_{i}$ 的总贡献为 $\displaystyle A_{i}\sum_{l=1}^{i}\sum_{r=i}^{N} \frac{1}{r-l+1}$  
记 $\displaystyle C_{i}=\sum_{l=1}^{i}\sum_{r=i}^{N} \frac{1}{r-l+1}$ ,则最终答案为 $\displaystyle \sum_{i=1}^{N} A_{i}C_{i}$  
> 3. 快速计算 $C_{i}$  
对于每个 $i$ 可设 $x=i-l$ 代表左端点与 $i$ 的距离  
由 $1\le l\le i$ 得 $0\le x\le i-1$  
再设 $y=r-i$ 代表右端点与 $i$ 的距离  
由 $i\le r\le N$ 得 $0\le y\le N-i$  
故 $r-l+1$ 可由 $x=i-l,y=r-i$ 代换为 $(y+i)-(i-x)+1=x+y+1$  
因此可得到 $\displaystyle C_{i}=\sum_{x=0}^{i-1}\sum_{y=0}^{N-i} \frac{1}{x+y+1}$  
> 4. 引入调和和 $H_{i}$  
定义 $\displaystyle H_{k}=\sum_{t=1}^{k} \frac{1}{t}$ ，其中 $H_{0}=0$  
对于 $\displaystyle \sum_{y=0}^{N-i} \frac{1}{x+y+1}$  
当 $y=0$ 时，分母为 $x+1$  
当 $y=N-i$ 时，分母为 $x+N-i+1$  
故  $\displaystyle \sum_{y=0}^{N-i} \frac{1}{x+y+1}=\frac{1}{x+1}+\frac{1}{x+2}+\dots+\frac{1}{x+N-i+1}$  
用调和和表示为 $H_{x+N-i+1}-H_{x}$  
因此  $\displaystyle C_{i}=\sum_{x=0}^{i-1}(H_{x+N-i+1}-H_{x})=\sum_{x=0}^{i-1} H_{x+N-i+1}-\sum_{x=0}^{i-1} H_{x}$   
> 5. 引入前缀和 $S_{i}$  
定义 $\displaystyle S_{k}=\sum_{t=0}^{k} H_{t}$  
对于第一部分 $\displaystyle \sum_{x=0}^{i-1} H_{x+N-i+1}$  
当 $x=0$ 时，下标为 $N-i+1$  
当 $x=i-1$ 时，下标为 $N$  
所以第一部分其实为 $H_{N-i+1}+H_{N-i+2}+\dots+H_{N}$  
即 $\displaystyle \sum_{x=0}^{i-1} H_{x+N-i+1}=S_{N}-S_{N-i}$  
对于第二部分 $\displaystyle \sum_{x=0}^{i-1} H_{x}$   
即 $H_{0}+H_{1}+\dots+H_{i-1}=S_{i-1}$  
那么 $C_{i}=S_{N}-S_{N-i}-S_{i-1}$  
得到最终答案 $\displaystyle \sum_{i=1}^{N} A_{i}(S_{N}-S_{N-i}-S_{i-1})$
> 6. 求 $i^{-1}(\bmod MOD)$  
> 设 $MOD=qi+r$ ,其中 $q=\left\lfloor\frac{MOD}{i}\right\rfloor,r=MOD\bmod i$  
因为 $MOD\equiv 0(\bmod MOD)$ 故 $qi+r\equiv 0(\bmod MOD)$  
因此 $r\equiv -qi(\bmod MOD)$  
两边同乘 $r^{-1}$ 可得到 $1\equiv -qi\cdot r^{-1} (\bmod MOD)$  
于是 $i\cdot (-qr^{-1})\equiv 1(\bmod MOD)$  
得到 $i^{-1}\equiv -qr^{-1}(\bmod MOD)$  
故最终公式为: $inv[i]=MOD-\left\lfloor\frac{MOD}{i}\right\rfloor\cdot inv[MOD\bmod i]\pmod{MOD}$  
代码为:
> ```cpp
> inv[1] = 1;
> for (int i = 2; i <= n; i++)
>     inv[i] = MOD - (MOD / i) * inv[MOD % i] % MOD;
> ```
