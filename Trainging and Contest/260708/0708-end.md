# 2234C.Vessels, Heights and Two Versions (Easy Version)
[Rating]1200
[Tag]DFS、并查集、贪心、模拟、双指针
## 题目介绍
There are $n$ communicating vessels of infinite height arranged in a circle. The base area of each vessel is $1$ cm$^2$, and between the $i$\-th vessel and the $(i \bmod n) + 1$\-th vessel there is a connection of negligible volume at height $h_i$ cm. For each vessel $i$, find the maximum total volume of water in cm$^3$ that can be placed in these vessels under the condition that the $i$\-th vessel remains empty.
Formally, you are given an array $h_1, h_2, \ldots, h_n$. A cyclic array of non-negative integers $w_1, w_2, \ldots, w_n$ is called good if the following holds:
-   For every $i$ from $1$ to $n$, if $\max(w_i, w_{i \bmod n + 1}) \gt h_i$, then $w_i = w_{i \bmod n + 1}$. In other words, if the maximum of two neighboring elements of the array $w$ exceeds the corresponding element of the array $h$, then these two neighboring elements of the array $w$ must be equal.
For each $i$ from $1$ to $n$, output the maximum possible sum $w_1 + w_2 + \ldots + w_n$ among all good arrays $w_1, w_2, \ldots, w_n$, under the condition that $w_i = 0$.
> $1<=t<=1000, 3<=n<=3000, 1<=h_{i}<=10^9$
## 补题情况
- 提交时间:21:57 状态:AC 详细状态:-
> 作者的题解比较绕，从容器 $l$ 到容器 $i$ 有顺时针和逆时针两条路
> 1. 在顺时针中， $w_{l+1}$ 的取值为 $max(w_{l}, h_{l})$   
> 由于 $w_{l}$ 必为空，那么 $w_{l+1}<=max(0,h_{l})$  
同理可得 $w_{l+2}<=max(w_{l+1},h_{l+1})<=max(h_{l},h_{l+1})$   
故容器 $i$ 的水位就是从容器 $l$ 到容器 $i-1$ 路径上管口的最高高度
> 2. 在逆时针中，同理也可得一样结果  
> 那么对于每个容器 $i$ ,其水位就是两个回路可得水位中的最高水位

# 2228B.Remilia Plays Soku
[Rating]1100
[Tag]博弈论，模拟
## 题目介绍
在这个游戏中，监管者要抓到逃脱者  
游戏场地由圆形排列的 $n$ 个位置组成  
监管者起初位于 $x_{1}$ ,逃脱者位于 $x_{2}$ ,且 $x_{1}!=x_{2}$  
每一秒，两人可以执行操作，但操作按以下顺序发生:
1. 逃脱者要么待在原地，要么移动到相邻位置，整个游戏中逃脱者最多可以移动 $k$ 次
2. 监管者观察逃脱者的位置后，要么移动到相邻位置，要么待在原地
3. 如果两次行动后他们的位置相同，监管者抓到逃脱者，游戏结束  
假设两人都发挥最佳水平，求自从游戏开始到监管者抓到逃脱者的时间
> $1<=t<=10^4, 2<=n<=10^8, 1<=x_{1},x_{2}<=n, x_{1}!=x_{2}, 0<=l<=10^8$
## 提交情况:
- 提交时间:22:48 状态:WA 详细状态:Wrong answer on test 2

    - 如果次数不够逃脱者逃脱到边界，那么逃脱者最多朝监管者的另一方向移动 $k$ 格，使得答案为 $x_{2}-x_{1}+k$

        - 如果逃脱者在逃脱到边界后，还有剩余次数的话，逃脱者可以在原地等待一段时间，这时间为`监管者到逃脱者相邻位置的时间`与`剩余次数`的最小值

# 2227D.Palindromex

## 题目介绍
存在一个长度为 $2n$ 的数组 $a$ , $[0,n-1]$ 的每个整数在数组中恰好出现两次  
寻找一个 $a$ 的子数组，使得这个子数组为回文子数组，且该子数组的mex最大，输出这个最大的mex
> $1<=t<=10^4, 1<=n<=10^5$
## 提交情况
- 提交时间:(07/09)00:12 状态:WA 详细状态:Wrong answer on test 2 
> 找到每个回文子数组的中心，然后寻找这个完整的子数组  
并将子数组内所有元素存入到`vector`，去重并排序  
如果首元素大于0，那么该子数组的mex就是0  
如果`vector`内存在差大于1的，那么就是小的那个加一
否则就是`vector`的末尾加一  
枚举 $a$ 中的所有回文子数组，找到最大的mex
- 补题
> 作者用了一个很巧妙的解法  
如果一个回文子数组的 $mex>1$ ，那么这个回文子数组必定包含0  
如果一个回文子数组的 $mex=0$ ，那么这个回文子数组同样包含0  
那么作者就从数组中的两个0入手，就有三种情况：
> - 第一个0为回文子数组的中心，第二个0为中心，两个0均为中心
> 那么就找到所有0的位置，然后枚举寻找回文子数组的mex即可
