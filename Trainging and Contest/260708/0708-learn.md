牛们并不喜欢这种布局，而且几头牛放在一个隔间里，它们就要发生争斗。为了不让牛互相伤害。约翰决定自己给牛分配隔间，使任意两头牛之间的最小距离尽可能的大，那么，这个最大的最小距离是多少呢？

# 二分训练总结与模版:
1. 对于二分寻找准确值的，有两种方法：
    1. 二分容器方法：
        1. `lower_bound`寻找第一个大于或等于的元素
        2. `upper_bound`寻找第一个大于的元素
    2. 二分手写方法：
        ```cpp
        int l = 0, r = x;   // 范围
        int ans = -1;       // 答案
        while (l <= r) {
            // 中间值，防止越界
            int mid = l + (r - l) / 2;
            if (mid == target) return mid;
            // 值小了，需要往右
            else if (mid < target) l = mid + 1;
            // 值大了，需要往左
            else if (mid > target) r = mid - 1;
        }
        ```
2. 最大化最小值
```cpp
int l = 0, r = x;   // 范围
int ans = -1;       // 答案
while (l <= r) {
    int mid = l + (r - l) / 2;
    if (check(mid)) {
        ans = mid;
        l = mid + 1;
    } else r = mid - 1;
}
```
3. 最小化最大值
```cpp
int l = 0, r = x;   // 范围
int ans = -1;       // 答案
while (l <= r) {
    int mid = l + (r - l) / 2;
    if (check(mid)) {
        ans = mid;
        r = mid - 1;
    } else l = mid + 1;
}
```
