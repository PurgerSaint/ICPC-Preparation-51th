## 题目介绍
> 给与一个长度不超过100、仅含拉丁字母的字符串`S`，要求对该字符串做以下操作：
- 删除所有辅音字母
- 在所有非辅音字母前面加入字符`.`，并将所有大写非辅音字母换成小写  
输出最终的字符串
## 提交详情：
- 提交时间:16:52 题目:118A 状态:WA 详细状态:Wrong answer on test 1  
> 我先是将所有大写辅音字母放到了`unordered_set`中，然后用以下方法保存小写字母:  
```cpp

    hash.insert('a' + (c - 'A'));
```  
然后就出现本地能正确输出，CF无法通过的问题了  
因为这会触发`编译器非定义内容`，CF的编译器可能在导入极少个小写元音后，触发重新哈希，导致循环提前结束，致使出现错误(仅有少部分小写元音)
- 提交时间:16:57 题目:118A 状态:AC 详细状态:-  
> 经Gemma4指出后，我才发现第一次提交的错误  
我是用额外的空字符串进行拼接，避免直接调用string类的插入使得出现"删除式的高复杂度"
> 删除式的高复杂度: 如vector的删除，是将该元素往后所有元素依次往前移动一个，容易出现O(n)的复杂度
> 出现非元音，就先加入字符，再根据题目条件进行转换模拟即可

# 122A.Lucky Division
[Rating]1000
[Tag]暴力枚举，数论
# 题目介绍
给与一个不大于1000的整数 $n$ ,判断其是否存在一个因子符合以下条件:
> 此数字仅包含4或7
# 提交详情:
- 提交时间:19:22 题目:122A 状态:AC 详细状态:-  
> 先以`for(int i=1;i*i<=n;i++)`找到 $n$ 的所有因子，然后对每个因子进行逐位判断  
非4且非7直接跳过，若只含4或7直接退出
- 提交时间:19:25 题目:122A 状态:AC 详细状态:-  
> 可以直接构造所有符合条件的数字，然后再根据构造的每个数字判断其是否为 $n$ 的因子  
由于题目给与的 $n$ 不超过1000，可以直接列出1000以下所有数字然后逐个枚举判断即可
- 提交时间:19:29 题目:122A 状态:AC 详细状态:-  
> 上一提交的构造办法，使用DFS进行构造:
```cpp
bool dfs(int d, int& n) {
    if (d > n) return false;
    if (n % d == 0) return true;
    return dfs(d * 10 + 4, n) || dfs(d * 10 + 7, n);
}
```
